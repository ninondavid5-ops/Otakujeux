# OtakuJeux — Renaissance V1

Prototype jouable d'un RPG fantasy anime/isekai.

## V1
- Histoire narrative en chapitres
- Protagoniste et Lyra, amie d'enfance
- Combat et boss
- XP, niveaux, statistiques
- Or et récompenses
- Guilde F → S
- Réputation dynamique
- Relation avec Lyra et synergie
- Missions et progression
- Sauvegarde locale
- Interface mobile/PC
- Aucun serveur requis

## Lancement
Le jeu est contenu dans `index.html`. Il peut être publié comme site statique.
